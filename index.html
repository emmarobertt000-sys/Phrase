BIP39 · Local-only wallet phrase utility

Generate and validate
12-word recovery phrases.

Create a fresh BIP39 mnemonic using your device’s cryptographic random number generator, or validate a phrase you already own. PhraseGuard does not send phrase text to a server.

Generate a new 12-word phrase

This tool creates a new BIP39 128-bit entropy phrase and verifies its checksum locally. Use only on a device you trust.

Security note: For a wallet holding funds, prefer the recovery process built into your hardware or reputable wallet. Never share your recovery phrase with anyone or enter it into a website you do not fully trust.

Validate a 12-word BIP39 phrase

Validation checks the English BIP39 word list and checksum. It does not check whether a wallet exists, is active, or has funds.

What this tool checks

  • Generator: Uses the browser’s cryptographic random number generator to create 128 bits of entropy, then builds the BIP39 checksum and 12-word phrase.
  • Validator: Confirms exactly 12 words, verifies each word is in the BIP39 English list, and checks the checksum.
  • Privacy: All phrase handling happens in your browser. This static demo has no server endpoint or analytics code.
A valid checksum only means the phrase is structurally valid. It does not prove ownership or identify a real wallet. Do not use this page to test random phrases against other people’s wallets.

This is a client-side demo. For production use, review the source, deploy over HTTPS, and audit dependencies and hosting. This page loads the BIP39 word list from a public GitHub raw URL when first used; for fully offline operation, bundle the list locally.

PhraseGuard is an independent utility and is not affiliated with OneKey. BIP39 is a mnemonic standard; compatibility depends on the wallet’s implementation.
